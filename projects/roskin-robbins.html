프로젝트 개요

ROS 2와 두산 M0609 협동로봇을 활용한 아이스크림 제조 자동화 프로젝트입니다. 키오스크 주문을 받아 컵 배치, 스쿠핑, 컵 투입, 스쿱 반환, 완성품 제공까지 순차적으로 수행하는 시스템을 구성했습니다.

저는 스쿠핑 공정과 힘 감지 로직을 담당했습니다. 재료 표면을 탐색하고, 접촉 후 추가 진입과 CURL 동작으로 재료를 퍼낸 뒤 기존 컵 이동 경로로 연결하는 제어 시퀀스를 구현했습니다.

해결하려던 문제

재료는 퍼낼 때마다 표면 높이와 형태가 달라집니다. 동일한 목표 좌표까지 하강하는 방식은 실제 표면과의 접촉 여부를 반영하기 어렵고, 진입이 부족하거나 과도해질 수 있습니다.

또한 스쿱의 자세에 따라 무접촉 상태에서도 힘 측정값에 편향이 생길 수 있습니다. 이를 반영해, 진입 직전 측정값을 기준으로 힘의 변화량을 계산하고 접촉을 판단하는 방식을 적용했습니다.

담당한 핵심 구현

구간구현 내용설계 목적
기준값 측정진입 자세에서 Fx/Fz를 5회 측정한 평균을 baseline으로 설정현재 자세에서 측정되는 힘을 비교 기준으로 사용
표면 탐색Z축을 1mm씩 하강하고, 힘 변화량 1.3N 이상을 연속 2회 확인순간적인 측정값만으로 접촉을 확정하지 않도록 구성
추가 진입접촉 위치에서 2mm 단위로 최대 7mm 진입하며 단계별 힘 확인한 번에 깊게 진입하는 동작을 분할
수직화·CURL현재 TCP 위치에서 자세를 수직화한 뒤 회전과 X축 후퇴를 결합접촉 이후 재료를 퍼담는 동작 구성
제한된 벽 접근벽 방향으로 2mm씩 최대 6mm 이동하며 반력 증가 확인충돌을 완료 조건으로 삼지 않고 이동 거리와 힘으로 접근 제한
후퇴·공정 연결후퇴와 수직 상승 후 현재 TCP에서 컵 이동 경로로 연결접촉 위치에 따라 달라지는 스쿠핑 종료점 반영

접촉 판단에는 다음 값을 사용했습니다.

ΔF = √((Fx − baselineFx)² + (Fz − baselineFz)²)

이 변화량은 접촉 탐색과 추가 진입 구간에 적용했습니다. 자세가 크게 바뀌는 CURL 이후에는 기존 진입 baseline을 그대로 적용하지 않고, 축별 절대 힘과 벽 접근 구간의 별도 기준값을 사용했습니다.

검사기준적용 범위·처리
표면 접촉 판정X/Z 합성 변화량 1.3N 이상, 연속 2회접촉 탐색 구간에서 접촉 확정
진입 델타 하드리밋X/Z 합성 변화량 15N 이상접촉 탐색·추가 진입 구간에서 후속 공정 중단
축별 절대 힘 제한Fx/Fy/Fz 중 어느 축이든 절댓값 40N 이상스쿠핑 중 각 힘 측정 지점에서 검사하고 후속 공정 중단
벽 방향 반력 증가벽 접근 시작 시 Fx − 현재 Fx가 5N 이상+X 접근을 마치고 후퇴 단계로 전환

힘은 각 이동이 끝난 뒤 측정하고, 제한값에 도달하면 후속 동작을 중단하도록 구성했습니다.

문제 해결 과정

진입 델타 또는 축별 절대 힘 제한에 도달하면 해당 단계에서 예외를 발생시켜 후속 공정을 중단하도록 구성했습니다. 벽 방향 반력 한계는 추가 접근을 끝내고 후퇴하는 조건으로 구분했습니다.

전체 시스템과의 연결

팀 시스템은 다음 흐름으로 구성되어 있습니다.

키오스크 주문
→ FastAPI·PostgreSQL
→ 주문 브리지
→ /make_icecream Action
→ 제조 공정 실행
→ 진행 상태·결과 반영

제 담당 범위는 이 중 제조 공정의 스쿠핑 구간입니다. 기존 UI·DB·Action 인터페이스를 유지하면서 스쿠핑 내부를 다음과 같이 구성하고, 기존 컵 투입·반환 동작으로 연결했습니다.

스쿱 파지·재료 위 접근
→ 기준값 측정·접촉 탐색
→ 제한된 추가 진입
→ 수직화·CURL
→ 제한된 벽 접근
→ 후퇴·상승
→ 현재 TCP에서 컵 투입 경로 연결
→ 배출·스쿱 반환

구현 결과

  • 표면 접촉을 힘으로 확인하고, 그 위치를 기준으로 후속 동작을 구성했습니다.
  • 접촉 판정, 진입 제한, 절대 힘 제한을 목적에 따라 구분했습니다.
  • 현재 TCP를 활용해 동적으로 달라지는 스쿠핑 종료 위치를 기존 제조 공정과 연결했습니다.
  • 스쿠핑 로직과 파라미터, 공통 로봇 API 처리를 분리해 수정 지점을 명확히 했습니다.
